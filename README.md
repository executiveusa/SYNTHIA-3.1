# SYNTHIA 3.1

The Kupuri Media operating system — one consolidated monorepo for Ivette's
AI agency. Voice-first, Mexican-Spanish-primary, revenue-generating.

Structured by the ICM / Model Workspace Protocol: numbered folders are stages,
markdown is the dispatch, the filesystem is the architecture.

## Structure

- `00-gateway/` — Ivette's personal 3D gateway (LOCKED)
- `01-public/` — Kupuri Media company site
- `02-cockpit/` — the master cockpit (desktop app, Phase C)
- `03-brain/` — the engine room (spheres, council, Supabase, API)
- `04-doctrine/` — design laws, UDEC rubric, Emerald Tablets
- `05-voice/` — the Alex voice engine

See `CLAUDE.md` for the full map and `AGENTS.md` for where things live.
